# M1.1 保留资产的依据与限制

> Status: HISTORICAL · 2026-11-07 汇编 · 结论来自 2026-11-05 / 06 的接收、整合与清理记录；本次未重新制作或代签验收

本文合并原 G2.4 基线、G2.5 V2 接收、M1.1 整合报告及相关实验经验。只保留仍影响现存人物和办公室的事实。实际文件与原件哈希以 [资产登记](../assets/registry.json) 为准，不再保留旧 viewer、命令、整包备份或已失效的证据链接。

## 批准范围的先后

1. G2.4 被用户确认为 A1.1 人物外观高模来源；办公室模块得到形体批准。它们不是正式动画或生产发布资产。
2. 用户在 Tripo 网页产生 V2；2026-11-06 接收审计保留减面成果，并记录拓扑和格式缺陷，当时没有把 V2 自动升级为动画母版。
3. M1.0 的 Mock 逻辑获阶段性认可，视觉未通过。M1.1 改用 V2 作为两位负责人、任务终端作为子 Agent，并复用已批准办公室模块。用户在后续 M1.2 任务中明确批准 M1.1 的视觉与功能。
4. M1.1 的移动是同一静态角色沿路径进行刚体调度，带临时底座提示；没有 Walk Clip，不能称为自然步行。
5. 2026-11-06 用户选择当前 B1 Web 为主线并清理旧试验。清理前核对 M1.1 检查点中的实际模型引用，保留人物 V2、办公室 portable GLB、母版、配套 FBX / 贴图和必要参考。旧工程随后已删除。

保留的两张 M1.1 实拍以 `M11-REFERENCE-READY` / `M11-REFERENCE-MEETING` 对应的登记为准；均为旧真实浏览器证据，软件渲染不证明目标 GPU 性能。三张 A1.1 图是概念参考，不是可编辑模型。

以下为原审计数值，本次文档整理没有重跑这些几何或 Validator 检查：

| 项目 | 原记录 |

| V2 GLB | 18,690 triangles；1 mesh / material；0 skin、morph、animations |

网页记录为 Quad、Smart Mesh P1.0、target 10,000；显示 40 积分但未核验账单。文件名 conversion UUID 不是已核实 task ID，不能称为已执行某个 API 模型版本。许可与发布权利缺口保持 unknown。

**静态 M1.1 外观批准不消除以上拓扑和格式问题。** 未来如果开展动画，应先明确局部修整、分件与变形证据，不因已有 UV 额外重复付费，也不凭面数下降宣布可动画。

## 清理后实际复验

2026-11-06 删除旧目录后，21 个保留文件与清理前 SHA-256 一致；两个办公室 Blender 文件用 5.2.3 LTS 只读重开成功，使用中的图片已打包，无链接库；三个保留 GLB 的 buffer / image 自包含。这里只证明原件保全与可打开性，未重新通过全部质量关卡。机器结果位置记录在 registry 的 `cleanup` 中。

## 仍有用的实验经验

- Snow / Fredy、程序化旧角色和 B2 S1 试验已退出当前资产路线，不能按旧版本号恢复为母版。
- 静态高密度网格、贴图外观、Quad 标签或自动 Rig 成功提示，都不能代替变形与身份保持证据。
- Blender 与 Web 的材质、透明、切线和阴影需要同机位复核；静态 unlit 烘焙不证明动态光照成立。
- 家具与地面的接触检查应覆盖框脚和边界；场景依赖更新后再执行保护断言，不能靠镜头遮挡解决结构问题。
- 未采纳或未测试不等于方法失败；同输入重复生成不构成改进。新尝试需说明方法变化、范围和停止点。

原报告中的大量诊断图和临时工程已在用户授权的资产清理中删除；本汇编是历史结论的保留，不声称它们仍可下载或复现。后续审查应基于保留原件和新的明确工作包。
