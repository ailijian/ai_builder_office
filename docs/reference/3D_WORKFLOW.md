# 后续 3D 资产流程参考

> Status: REFERENCE · 2026-11-07 · 当前暂停；不是 Web 迭代的前置任务或待办队列

当前主线见 [项目状态](../STATUS.md)。本机仅保留 `assets/retained-3d/` 中的人物和办公室两类资产；登记取 [机器登记](../assets/registry.json)。旧试验目录已删除，B2 S1 已结束，不继续旧 S2 提案。

## 保留原则

- 人物：G2.4 外观来源、M1.1 使用的 V2 与配套 FBX / 贴图；外观批准不等于正式动画就绪。
- 办公室：批准环境母版、来源 Blender 与 M1.1 portable GLB；保留源文件、打包贴图和可重开能力。
- 不重新生成或覆盖批准原件。新的资产制作使用独立版本，并明确模型身份、输入与哈希。
- 旧工具、Skill、额度记录或历史提案的存在不授权生成、上传、消费或动画制作。

## 将来重新授权后的流程

1. 明确工作包：输入资产 ID / 哈希、修改内容、目标平台、成本与停止点。
2. 接收或制作独立版本，记录来源和真实结构；生成参数或权利缺失保持 unknown。
3. 检查身份、拓扑、分件、材质和本轮确需的骨骼 / 动作；技术标签不替代主创审美。
4. 保留可编辑 Blender 和未压缩导出，再验证 GLB 的材质、节点、skin / morph / Clip 与依赖。
5. 只有获准接入时，才进入 Web 加载、交互、性能与主创验收；不自动替换 B1 的 PNG 展示层。

## 质量关卡

沿用 QG-0 至 QG-6；历史 G0–G4、Q0–Q4、Gate A–D 的批准只在原范围有效，不自动换算成下列全部通过。

| 关卡 | 必要证据与通过条件 | 失败 / 未验证的去向 |
| --- | --- | --- |
| QG-0 输入与授权 | 路径/哈希/版本/来源登记；保护原件；本轮范围、成本和输出明确。发布前补齐权利记录 | 缺来源记录标 unknown；不猜 task ID。许可未核实不对外发布；费用未授权不提交 |
| QG-1 身份与外观 | 与 G2.4 / A1.1 的正面、3/4、侧背、Clay、100%/实际小尺寸对照；轮廓、五官、服装气质得到主创认可 | 低模自动生成身份偏移即拒收，不自动替换母版 |
| QG-2 拓扑与编辑 | 真实网格/UV/材质统计，眼口/手/关节边流和必要分件；单位、Root、挂点清楚；`.blend` 可重开 | 仅面数下降或 Quad 不算通过；回退局部结构，保留原高模 |
| QG-3 骨骼与表情动作 | 本轮 manifest 约定的骨架、权重、morph、Clip 实际存在；Blender 检查中间帧/极值、闭眼、微笑及约定肢体动作，无明显破损、穿插、脚滑 | 自动 Rig 成功不算自然动作；回到 rest pose/蒙皮/局部拓扑，不扩大动作库 |
| QG-4 导出与格式 | 未压缩 GLB 与可选压缩副本；inspect + Khronos Validator；核对节点、skin、morph、Clip、纹理、解码器；源文件哈希保持 | Validator 错误须处理；warning/info 分类说明，不能为消除提示改原件或删除期望数据 |
| QG-5 实际 Web | Three.js/R3F 实际加载/播放；Playwright 固定镜头/帧及约定交互，0 未解释的加载或脚本错误；Blender/Web 材质差异记录；目标设备测量 | 软件渲染可做加载检查，不能证明真实 GPU 性能；未测平台标未验证 |
| QG-6 主创与发布判定 | 适用证据、已知限制、许可证、性能与视觉均被审阅；批准人/日期/精确版本和范围可追溯 | 未获人工批准不得宣称 Production Ready；不自动发布或进入下一阶段 |

静态高模可获“外观批准”，不因此通过 QG-2/3/5/6。局部拓扑小样不要求完整动作库；未制作项标“本轮不适用/后续未完成”，不能写为通过。**GLB 格式成功 ≠ 视觉成功；Blender 渲染成功 ≠ WebGL 一致。**

## 资源预算：单一口径

当前没有已批准的正式动画角色数值预算。旧文档中的 15–40k、20–45k、40–80k 等是不同实验估算，均不作为并行强制要求；不要取最小值强制降面，也不要取最大值当放行标准。

每个获授权工作包在候选处理前记录目标设备/GPU/浏览器、viewport/DPR、角色屏幕占比、并存数量、阴影/后处理配置，给出本次拟议预算及依据。主创确认视觉取舍后，把预算写入该版本 manifest/报告。没有设备数据时只记录测量和“预算待定”，不得声称性能合格。

| 指标 | 统一统计要求 |
| --- | --- |
| 几何 | 分开记录源 polygons、求值后三角形、GLB 唯一几何三角形及运行时实例合计；Quad 不是一个 triangle |
| 资源体积 | 标明 bytes、十进制 MB 或 MiB；分别记录未压缩/压缩文件、传输量与解码成本 |
| 贴图 | 数量、尺寸、色彩空间/通道、压缩格式；估算内存与实测显存分开 |
| 渲染 | draw calls 注明是否含阴影/多 pass；帧时间记录采样窗口及分位数，不只报瞬时 FPS |
| 动画 | 骨骼数、权重、morph、Clip、实例数与更新成本；记录独立播放和过渡表现 |
| 视觉 | 同机位/同尺度/同光照对比；概念图仅可近似匹配，真实 Blender/Web 相机可固定 |
